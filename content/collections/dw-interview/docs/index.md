# 数据仓库八股 · 数据开发岗面试课

面向数据开发岗位实习面试的系统化学习笔记，覆盖 51 道高频数据仓库面试题。

## 课程结构

| 模块 | 主题 | 覆盖原题数 |
|------|------|-----------|
| L01 | 数仓定位与架构 | 7 |
| L02 | 建模基础 | 8 |
| L03 | 缓慢变化维度(SCD) | 5 |
| L04 | 建模进阶 | 4 |
| L05 | ETL/ELT 与离线链路 | 6 |
| L06 | 查询性能与分层优化 | 12 |
| L07 | 实时数仓与治理收尾 | 10 |

## 学习建议

- **递进主干**：L01 → L02 → L03 → L05 → L07 形成"定位→建模→处理→链路→实时"主路径
- **独立深入**：L04 是 L02 的进阶扩展，L06 贯穿所有模块的性能优化视角
- **项目绑定**：每个模块的面试嘴替都绑定真实项目经验（Kafka→Flink→ClickHouse 实时数仓链路、ODS/DWD/DWS/DM 分层）
- **验证标准**：`mkdocs build` 零警告零错误
