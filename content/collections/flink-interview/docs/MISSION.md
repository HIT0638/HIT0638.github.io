# MISSION · 为什么学这个

## 一句话目标
为**数据开发（大数据开发）岗**的面试，系统打通 Flink 八股，并能把知识点串成可背诵、可临场发挥的面试表达。

## 背景与动机
- 已有《Flink八股筛选与学习计划.md》：74 道题、按 17 主题聚类、A/B/C/D 优先级、7 天顺序、项目绑定模板。
- 痛点是"逐题碎片背诵 → 上下文反复切换、记不牢、面试讲不连贯"。
- 诉求：把每天一簇主题合成**厚重的一课**，概念 → 机制 → 代码 → 项目绑定 → 自测，一条线打通。

## 学习者画像
- 哈尔滨工业大学 软件工程学士，在读 计算机科学与技术 硕士。
- 有扎实的 CS/Java/分布式基础，不需要从零讲概念。
- 目标岗位：数据开发（大数据开发）。技术栈涉猎：flink / hdfs / redis / mysql / spark / kafka / iceberg。

## 范围（本次）
- **本次只做 Flink 专项**，共 7 个 mega-lesson（一课 = 原计划的一天）。
- 项目绑定先复用计划文件里的 5 套通用模板，真实项目由学习者后续替换。
- 代码：课内嵌可背诵 Java 片段；`code/` 放 1~2 个完整可跑 Job 作为真理解抓手。

## 成功标准
- 能不看笔记，把 A 类题（定位/架构/状态/窗口/Watermark/Checkpoint/Exactly-once/反压/Join/去重）讲成一条连贯故事线。
- 能写出核心 API 片段（window+watermark、KeyedState、Kafka source/sink、两阶段提交 sink）。
- 能用自己的项目链路（或模板）把八股"落袋"成面试口径。

## 扩展位（后续）
本次只吃透 Flink。MISSION 预留向整个数据开发技术栈扩展：
- kafka（消息系统/分区/精确一次）、iceberg（湖仓表格式）、redis（缓存/维表/去重）、
- spark（批/微批对比）、hdfs / mysql（存储与数仓底座）。
后续可作为独立章节平滑接入本课体系。
